贪吃蛇 — 麒麟 V10 SP1 x64 便携版
====================================

一、运行方法
----------
1. 解压本目录到任意可写位置(如 ~/apps/snake-game)
2. 打开终端,进入目录执行依赖检测:
     ./check-deps.sh
   全部 [OK] 即可直接运行:
     ./snake-game
   (麒麟桌面可直接双击 snake-game 运行;若无反应,请先用终端运行看报错)

二、依赖说明
----------
程序依赖系统图形库(麒麟 V10 SP1 桌面版软件源内均有):
     libwebkit2gtk-4.0-37 (2.38.x)
     libgtk-3-0           (3.24.x)
如检测提示缺失,请从内网软件源安装:
     sudo apt install libwebkit2gtk-4.0-37 libgtk-3-0
程序运行全程不联网。

三、操作
----------
方向键 / WASD  移动
空格 / P       暂停、继续
Enter          开始 / 再来一局
Esc            暂停
切换窗口时自动暂停

四、数据存放
----------
最高分记录保存在:
     ~/.config/wails-snake/scores.json
删除该文件即可清空纪录。

五、常见问题
----------
Q: 双击没反应?
A: 先在终端运行 ./check-deps.sh 和 ./snake-game 查看输出;
   若报权限问题,执行 chmod +x snake-game。
Q: 界面字体异常?
A: 程序使用系统自带中文字体,麒麟默认字体即可。
