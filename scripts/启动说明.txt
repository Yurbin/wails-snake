贪吃蛇 — 麒麟 V10 SP1 x64 便携版
====================================

一、运行方法
----------
1. 解压本目录到任意可写位置(如 ~/apps/snake-game)
2. 打开终端,进入目录执行依赖检测:
     ./check-deps.sh
   全部 [OK] 即可直接运行:
     ./snake-game
   (麒麟桌面也可直接双击 snake-game 运行;若无反应,请先用终端运行看报错)

二、开始菜单与卸载
----------
首次运行游戏后,会自动在开始菜单创建:
     贪吃蛇        —— 点击即启动游戏
     卸载贪吃蛇    —— 点击即从开始菜单移除本程序
菜单项会自动指向程序当前所在目录;若移动了程序目录,
重新运行一次游戏即可自动修正菜单项。
也可在终端手动卸载菜单集成:
     ./snake-game --uninstall
彻底删除 = 卸载菜单项后,手动删除程序目录;
最高分记录在 ~/.config/wails-snake/(可一并删除)。

注:若本机用 deb 安装包(sudo apt install ./wails-snake_*.deb)
安装过系统级版本,程序会检测到并跳过用户级菜单集成,
此时请统一用 "sudo apt remove wails-snake" 卸载。

三、依赖说明
----------
程序依赖系统图形库(麒麟 V10 SP1 桌面版软件源内均有):
     libwebkit2gtk-4.0-37 (2.38.x)
     libgtk-3-0           (3.24.x)
如检测提示缺失,请从内网软件源安装:
     sudo apt install libwebkit2gtk-4.0-37 libgtk-3-0
程序运行全程不联网。

四、操作
----------
方向键 / WASD  移动
空格 / P       暂停、继续
Enter          开始 / 再来一局
Esc            暂停
切换窗口时自动暂停

五、数据存放
----------
最高分记录保存在:
     ~/.config/wails-snake/scores.json
删除该文件即可清空纪录。

六、常见问题
----------
Q: 双击没反应?
A: 先在终端运行 ./check-deps.sh 和 ./snake-game 查看输出;
   若报权限问题,执行 chmod +x snake-game。
Q: 开始菜单里没有图标?
A: 程序目录需要可写(图标写入 ~/.local/share/icons);
   运行一次游戏后重新打开开始菜单即可。
Q: 界面字体异常?
A: 程序使用系统自带中文字体,麒麟默认字体即可。
